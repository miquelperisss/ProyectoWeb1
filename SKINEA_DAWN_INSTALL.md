# Skinea Dawn theme installation

This package contains three Shopify Online Store 2.0 section files for the Dawn theme:

- `sections/skinea-mega-menu.liquid`
- `sections/skinea-premium-home.liquid`
- `sections/skinea-product-results.liquid`

## Where to paste the code in Shopify

1. In Shopify Admin, go to **Online Store > Themes**.
2. On your Dawn theme, click **... > Edit code**.
3. Open the **Sections** folder.
4. Click **Add a new section**.
5. Create these three files one at a time:
   - `skinea-mega-menu`
   - `skinea-premium-home`
   - `skinea-product-results`
6. Paste the full matching Liquid code from each file in this repository into the matching Shopify section file.
7. Click **Save** after each file.

## How to add the sections in the Theme Editor

1. Go to **Online Store > Themes > Customize**.
2. Open the **Header** area and add **Skinea mega menu**.
   - If Dawn's default header is still visible, hide or remove duplicate menu items so shoppers do not see two competing navigations.
3. Open the **Home page** template and add **Skinea premium home** near the top of the page.
   - Use the Theme Editor blocks to add best sellers, concern cards, before-and-after cards, UGC reviews, benefit icons and FAQs.
4. Open **Products > Default product** and add **Skinea product results** below the main product information section.
   - Keep sticky add to cart enabled if you want a fixed mobile-first conversion bar.

## Editable content

All images, headings, text, buttons, links, colors, products, reviews, FAQ items, concern cards and sticky add-to-cart labels are editable in the Shopify Theme Editor.
